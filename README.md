## Research thesis

AI does not need human-like subjective experience to be a powerful scientific instrument. World Mechanics separates five increasingly strong claims:

1. **Representation** — learned structure
2. **Prediction** — generalisation beyond observed examples
3. **Intervention** — reliable control or experimental action
4. **Mechanistic explanation** — causal, testable account of computation
5. **Subjective experience** — first-person phenomenal consciousness

Evidence for levels 1–4 does not by itself establish level 5.
