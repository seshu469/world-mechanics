## Publish the site (free)

1. Create a public GitHub repository.
2. Upload these three files to the root.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Wait a minute. Your URL will be `https://YOURUSER.github.io/REPO/`.

Alternatives: Netlify, Cloudflare Pages, Vercel — drag the folder.

## Publish the paper as a preprint

- Site: already published when the site is live (`PAPER.md` is linked).
- arXiv: convert to LaTeX, create an account, first-time submitters may need an endorser. arXiv is not peer review.
  https://info.arxiv.org/help/submit/index.html
